CipherNest is a zero-knowledge cloud storage app for Android: files are encrypted on your device before they are uploaded, so no server, including ours, can read them.

- Website: https://ciphernest.io
- Google Play: [PLAY STORE LISTING URL]
- Security policy and vulnerability reporting: https://ciphernest.io/security

**Verifying a release.** Every release on the Releases page lists a SHA-256 checksum next to its APK. Download the APK, compute its SHA-256 locally (`sha256sum ciphernest-<version>.apk` on Linux or macOS, `Get-FileHash` in PowerShell on Windows), and confirm the value matches the one published for that release before installing.
